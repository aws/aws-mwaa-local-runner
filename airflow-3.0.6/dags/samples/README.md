# Sample DAGs

This folder contains sample DAGs demonstrating Airflow 3.0.6 features.

## Available Samples

- **`sample_dag_mwaa_3_0.py`** - Basic sample DAG for testing (Bash and Python operators)
- **`sample_taskflow_api_dag.py`** - TaskFlow API example (recommended modern approach)
- **`sample_airflow_3_syntax_dag.py`** - New syntax and migration examples (schedule, logical_date, etc.)

## Usage

These DAGs are automatically discovered by the Airflow scheduler. They are provided for reference and learning purposes.

For more information about Airflow 3.0.6 features, see:
- [Airflow 3.0.6 New Features](../../docs/AIRFLOW_3.0.6_NEW_FEATURES.md)
- [Differences from 2.10.3](../../DIFFERENCES.md)
- [TaskFlow API Migration](../../docs/TASKFLOW_API_MIGRATION.md)
